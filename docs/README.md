## このプロジェクトでの構成
- `project-plan.md`: プロジェクト全体の目的と完成条件
- `setup/`: 環境構築の記録
- `design/`: 設計判断の記録
- `learning-log/`: 実装ごとの学習ログ

## このプロジェクトでの運用メモ
- 実装と同時に docs も更新する
- 環境構築は `setup/` に分離する
- 設計判断は `design/` に残す
- 日ごとの進捗は `learning-log/` に残す
- 実行コマンド、書き換えたファイル、変更理由をできるだけ具体的に残す
