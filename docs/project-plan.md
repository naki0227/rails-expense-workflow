# Rails Expense Workflow

## 目的
Ruby on Railsで業務システムらしいワークフローを実装し、RailsのMVC、状態遷移、権限管理、テストを実務寄りに理解する。

## 作るもの
社内経費申請システム

## 想定ユースケース
- 社員が経費申請を作成する
- 上長が承認 / 差し戻しする
- 管理者が申請状況を一覧管理する
- 添付ファイルやコメントを扱える

## 必須機能
- ログイン機能
- 経費申請の作成 / 編集 / 一覧
- 承認 / 差し戻しの状態遷移
- コメント機能
- 添付ファイルアップロード
- 管理者画面
- テスト

## 使う技術候補
- Ruby
- Ruby on Rails
- MySQL または PostgreSQL
- Devise
- Active Storage
- RSpec
- Docker

## 意識したい設計
- RailsらしいMVC
- モデルに責務を寄せすぎない設計
- バリデーションと状態遷移の整理
- ロールごとの権限制御
- 業務フローを見通しよく表現すること

## このプロジェクトで身につけたいこと
- Railsでの業務アプリ設計
- 承認フローの実装
- バリデーション設計
- 権限管理
- Railsのテスト文化

## 完成条件
- READMEがある
- Dockerで起動できる
- ログインから申請、承認まで一連で動く
- 主要ユースケースに対するテストがある
