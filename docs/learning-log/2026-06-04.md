## 実行したコマンド
```sh
rbenv local 3.3.11
gem install rails
rbenv rehash
rails -v
brew services start postgresql@18
bin/rails db:create
bundle install
bin/rails generate rspec:install
bundle exec rspec
bundle exec rubocop
git add .
git commit -m "Initialize Rails expense workflow app"
git push -u origin main
```
